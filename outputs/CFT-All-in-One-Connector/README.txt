CFT ALL-IN-ONE CONNECTOR
========================

CFT All-in-One Connector is the central desktop application for Core Flight
Tech flight simulation hardware. It is designed to detect connected CFT
products, identify the active flight simulator, and use the appropriate
product and simulator profile automatically.

INCLUDED UNIFIED PROJECTS
-------------------------
- Microsoft Flight Simulator + PMDG 737
- X-Plane + Zibo 737

Each project includes NAV, COMM, ADF, ATC, EFIS, MCP, and Compact Overhead
configurations. Only connected Core Flight Tech products are bound and used.

QUICK START
-----------
1. Connect the Core Flight Tech device to a USB port.
2. Start the supported simulator and aircraft.
3. Run CFT All-in-One Connector.exe.
4. Wait for device lookup, simulator detection, and project initialization.
5. Click CONNECT when the button becomes available.
6. Enable Debug in the lower-left corner for live engine diagnostics.

DEBUG CONTROLS
--------------
- PAUSE / RESUME pauses only the visible log stream.
- CLEAR clears the visible log history.
- COPY copies the visible log to the clipboard.
- Resize the window from any edge or corner to enlarge the Debug panel.

PACKAGE CONTENTS
----------------
- Engine: hidden CFT connection engine and runtime dependencies
- Profiles: Core Flight Tech product and simulator profiles
- LICENSE-MobiFlight.txt: original MobiFlight MIT License

Closing the application also stops the hidden engine and releases the serial
port. The standard MobiFlight installation is not modified.
