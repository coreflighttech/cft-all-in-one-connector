CFT ALL-IN-ONE CONNECTOR - PROFILES
===================================

This directory contains MobiFlight profiles for Core Flight Tech products and
supported flight simulators.

The application selects one unified aircraft project automatically according
to the running simulator.

Included projects:
- MSFS20_PMDG737.mfproj: Microsoft Flight Simulator with PMDG 737
- XP12_ZIBO737.mfproj: X-Plane with Zibo 737

Each project embeds the configurations for seven Core Flight Tech product
families. Connected products are matched by the engine through MobiFlight's
native auto-binding behavior.

Do not rename the included project files. Their names are used by the automatic
simulator selection logic.
