# CFT All-in-One Connector Engine

This source tree contains the customized MobiFlight-based runtime engine used by CFT All-in-One Connector.

The CFT application is intended to detect Core Flight Tech hardware, identify the active flight simulator, and load the appropriate product/simulator profile while presenting a compact user interface.

The upstream MobiFlight documentation remains available in `README.md`. The original MIT License is retained in `LICENSE`.
